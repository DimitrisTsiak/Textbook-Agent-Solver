# Linear Algebra Textbook Exercise Solver

An agentic AI solver for Jim Hefferon's undergraduate textbook *Linear Algebra*. The system parses the LaTeX source code of the textbook, embeds the core content (definitions, theorems, lemmas, corollaries, examples), constructs a chronological concept dependency graph, and sequentially solves exercises, building on solutions to prior exercises.

## Book Information
* **Book**: *Linear Algebra* (4th Edition) by Jim Hefferon
* **Author**: Jim Hefferon 
* **Download Source / Links**: [hefferon.net/linearalgebra](https://hefferon.net/linearalgebra) (The raw source files are located in the `linear-algebra-master` folder).
